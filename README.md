# AetherDrop — AI Dropshipping Store

AI-powered dropshipping website focused on **Electronics**, **Technology Accessories**, and **Vehicle Accessories**.

## Live Site

Once GitHub Pages is enabled, the site will be available at:

**https://marcusjasson5-dotcom.github.io/aetherdrop-ai-store/**

## Features

- Modern dark UI
- Product catalog with sample electronics & car accessories
- AI product research messaging
- Pricing tiers
- Contact / lead capture form
- Fully responsive

## Local Development

Just open `index.html` in a browser, or run a simple server:

```bash
python3 -m http.server 8080
```

## Customization

- Edit products in `js/app.js`
- Update branding/colors in `index.html` and Tailwind config
- Connect the contact form to Formspree, EmailJS, or your own backend
